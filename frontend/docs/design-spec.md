# DormTopology 3D 寝空拓扑 — 前端信息架构与视觉设计方案

版本：v0.1（设计阶段）｜日期：2026-10-12｜状态：待评审，可直接用于开发

---

## 0. 产品范围与设计原则

面向高校宿舍「上床下桌」场景的桌面整理与智能理线工具。核心流程：
**创建项目 → 配置空间 → 上传照片 → 确认识别物品 → 生成/加载 3D 资产 → 空间整理 → 线缆规划 → 输出执行指南。**

设计原则：

1. **三维优先**：三维场景占据工作台 ≥ 60% 面积，UI 面板克制、低饱和，不与场景争夺注意力。
2. **模式降复杂度**：「整理物品 / 规划走线」两种模式互斥切换，同一时刻只暴露当前任务的工具与高亮。
3. **数据来源透明**：演示数据、本地/真实计算结果、未接入能力三态必须在界面上可区分（见 §8.5）。
4. **可回改**：识别结果、空间参数、物品分类尺寸在任意阶段可返回修改，修改后不清空已完成工作，只标记受影响项。
5. **失败可继续**：长耗时任务支持等待/失败/重试/部分成功，允许用占位资产降级推进。

## 1. 页面与路由清单

| 路由 | 页面 | 说明 |
|---|---|---|
| `/` | 项目入口 | 最近项目、创建项目、打开演示项目 |
| `/project/:projectId/setup/space` | 空间配置 | 模板、尺寸、书架、立柱、出线孔、电源、三维预览 |
| `/project/:projectId/setup/photos` | 照片导入与物品确认 | 内部 4 步：上传 → 识别 → 确认物品 → 资产生成；含长任务状态区 |
| `/project/:projectId/workbench` | 三维工作台 | `?mode=organize\|cable`、`?compare=1&plan=A\|B`、`?focus=item:xxx` |
| `/project/:projectId/deliver` | 方案交付 | 整理步骤、走线次序、配件建议、导出 |
| `/demo` | 演示入口 | 一键创建 `projectId=demo` 的演示项目并跳转 `/project/demo/workbench` |
| `*` | 404 | 提示并返回入口 |

约定：

- `projectId` 为本地生成的 nanoid；`demo` 为保留 ID。
- 路由守卫：项目不存在 → 重定向 `/` 并提示；`deliver` 未达到完成条件 → 显示阻断态并提供「返回工作台」。
- 步骤导航常驻顶部：`① 空间配置 ② 照片物品 ③ 工作台 ④ 方案交付`，已到达过的步骤可点击回跳。

## 2. 主用户流程与返回修改路径

```
入口 / ──创建──▶ 空间配置 ──▶ 照片导入 ──▶ 三维工作台 ──▶ 方案交付
   │                ▲    │          ▲    │        ▲    │
   └──演示项目───────┘    └──回改─────┘    └──回改───┘    └──回看步骤
```

### 返回修改路径（全部保留已完成工作）

| 场景 | 入口 | 行为 |
|---|---|---|
| 工作台上发现桌面尺寸不对 | 顶栏步骤「① 空间配置」 | 进入空间配置，改完「保存并返回」→ 回工作台；受影响物品标记「待重摆」并黄点提示，其余保持 |
| 某物品识别错误（分类/数量/接口） | 属性面板「重新识别」、物品卡片右键 | 侧滑抽屉展示该物品在照片上的标注与识别字段；确认后**原地更新**，不重置其他物品摆放 |
| 想补传照片新增物品 | 工作台左面板「+ 添加物品」 | 打开照片页第 1 步（追加模式），新物品识别确认后加入左面板「未放置」区 |
| 交付页发现某步太复杂 | 步骤卡片「回到工作台查看」 | 带 `?focus=` 定位到对应物品/线缆并高亮 |
| 未保存离开 | 全站路由拦截 | 自动本地草稿保存（Zustand persist），拦截仅在导出中等危险操作时提示 |

## 3. 各页面主要操作与完成条件

### P1 项目入口 `/`

- 操作：最近项目卡片（继续 / 重命名 / 删除）；「创建项目」；「打开演示项目」；拖入 `.dtop.json` 导入（后续版本）。
- 完成条件：选中或创建项目，进入该项目的**最近未完成步骤**（新项目 → 空间配置）。

### P2 空间配置 `/setup/space`

- 操作：
  - 宿舍模板：上床下桌标准款 / 加长款 / 自定义（模板只预填参数，均可再改）。
  - 桌面：长 120–220cm、宽 50–90cm、厚 1.8–5cm，预设按钮 + 数值输入（cm，0.5 步进）。
  - 书架：层数 0–3、离桌高度、深度。
  - 立柱：床架立柱数量与位置（左右/四角），截面尺寸。
  - 出线孔：位置（桌面坐标）、直径 40–80mm，可多个。
  - 电源：插座/插排，位置、数量、面板朝向。
  - 三维预览：旋转/缩放；点击场景标记点直接编辑对应参数（双向联动）。
- 完成条件：桌面尺寸合法；出线孔 ≥ 1、电源 ≥ 1；无未保存修改。点击「下一步」自动保存。

### P3 照片导入与物品确认 `/setup/photos`

内部步骤条：**1 上传 → 2 识别 → 3 确认物品 → 4 生成资产**。

- 步骤 1 操作：拖拽/选择 1–6 张照片（桌面整体、桌下、走线特写建议位）；或「跳过，使用演示物品库」。完成条件：≥1 张上传成功，或选择跳过。
- 步骤 2 操作：查看逐图识别进度（整体百分比 + 每图状态）；失败单图可重试或标记「跳过此图」。完成条件：所有图片识别完成或其状态被用户处置。
- 步骤 3 操作：左侧照片标注框 ↔ 右侧物品列表双向高亮；逐项编辑**分类（三大类预设）、名称、数量、尺寸（长宽高 cm）、电气设备的接口**（接口类型：国标两孔/三孔/USB-A/USB-C/网口/HDMI 等，数量、线长预估）。可合并重复项、删除误识别项、手动添加漏识别项。完成条件：每项具备分类 + 尺寸 +（电气项）接口，或显式标记「无需处理」。
- 步骤 4 操作：每项选择资产来源：**资产库加载 / AI 生成（Rodin）/ 占位盒**；查看生成队列（等待/进行中/失败重试/部分成功）。完成条件：所有物品生成成功**或**用户选择占位/跳过；点击「进入工作台」。

### P4 三维工作台 `/workbench`

- **整理物品模式**：
  - 左侧面板：未放置 / 已放置，按三大分类分组（§5）；点击或拖拽物品 → 在桌面点击放置，自动吸附网格与桌缘，校验越界/悬空。
  - 属性面板：位置 (x,y,z)、旋转（90° 步进）、尺寸微调、分类、备注。
  - 底部状态区：物品计数（已放置 n/m）、整理度、操作提示、任务队列摘要。
- **规划走线模式**：
  - 从设备接口拖出线缆 → 途经通道节点（桌沿卡扣位 / 桌底走线槽 / 立柱绑扎点 / 出线孔）→ 终点电源；就近 6cm 内自动吸附通道。
  - 属性面板：线缆类型（电源红 / 网线蓝 / 数据紫 / 充电琥珀）、自动计算长度（+8% 余量，标注「计算值」）、接头、固定配件（理线扣/魔术贴/扎带）。
  - 校验提示：交叉过多、悬空段、长度不足、同一插排过载（接口数）。
- 通用：顶栏视角预设（正前/俯视/左视/右视/桌面视角）、撤销 (Ctrl+Z)、重做 (Ctrl+Shift+Z)、重置视角 (F)、**方案对比**。
- 完成条件（「生成方案」按钮解锁条件）：所有已放置物品无越界；每台电气设备线缆抵达电源或标记「无需理线」；无致命冲突（红色校验项为 0，黄色项已确认忽略）。

### P5 方案交付 `/deliver`

- 操作：浏览整理步骤清单（按区域排序，含前/后示意缩略图）；走线次序（1→n 步骤卡：从哪到哪、配件、长度）；配件建议清单（数量可调，标注演示/计算来源）；导出 PDF 执行指南 / 步骤图卡 PNG / 方案 JSON。演示模式下导出带「演示」水印说明。
- 完成条件：用户确认步骤（勾选/一键确认）且（可选）导出成功。

要点：顶栏含模式切换 + 视角 + 撤销/重做/重置视角 + 方案对比；左侧三大分类；右侧随选中对象显示**尺寸、位置、分类、接口**；底部为任务状态 + 操作提示 + 计数 + 整理度。

### 4.2 模式差异

- **整理物品**：左面板活跃；走线相关按钮隐藏；场景显示桌面网格与吸附提示；越界/悬空校验红黄框。
- **规划走线**：左面板变为「设备接口列表 + 线缆列表」；场景显示通道节点（桌沿/桌底/立柱/出线孔）与已布线缆；整理尺寸编辑置灰。

### 4.3 方案对比

点击「方案对比」→ 视口切换为**并排 A/B**（或叠加切换器）；两侧各自 3D 场景同步相机；顶部条显示差异摘要（物品位置差异 n 处、线缆路径差异 n 条）；操作：「采用 A / 采用 B / 退出对比」。

### 4.4 小屏适配（<768px）

- 顶部工具栏横向滚动，「更多」收纳次要项；模式切换保持为分段控件。
- 左/右面板变为**底部抽屉**，通过底部 Tab（物品 / 属性 / 任务）切换；同一时刻仅一个抽屉打开。
- 三维视口保留在表格上方主位；视角操作复用双击 + 手势。

## 5. 视觉规范

### 5.1 色彩（语义令牌，shadcn/ui 兼容 CSS 变量）

| 令牌 | 值 (HSL) | 近似色 | 用途 |
|---|---|---|---|
| `--background` | `36 33% 97%` | #FAF8F5 暖白 | 应用底色 |
| `--surface` | `0 0% 100%` | #FFFFFF | 卡片/面板 |
| `--surface-muted` | `42 20% 93%` | #F1EFEA 浅灰 | 分区、悬停底色 |
| `--border` | `40 14% 87%` | #E5E1D8 | 分隔线、描边 |
| `--foreground` | `210 7% 16%` | #26292C 石墨 | 正文 |
| `--muted-foreground` | `220 6% 38%` | #5A5F66 | 次要文字 |
| `--faint-foreground` | `220 6% 60%` | #8A8F96 | 占位/禁用 |
| `--primary` | `172 82% 34%` | #0F9D8A 青绿 | 主操作、选中、进度 |
| `--primary-hover` | `172 82% 29%` | #0C8776 | 悬停/按下 |
| `--primary-soft` | `172 55% 94%` | #E6F4F1 | 主色浅底、选中行 |

### 5.2 三维场景色彩

| 元素 | 色值 | 说明 |
|---|---|---|
| 桌面（浅木） | #D6B98C，木纹 #C9A06A | PBR 粗糙度 0.7 |
| 床架（深色金属） | #3A3F45，金属度 0.6 | 立柱/横梁 |
| 墙体/地面 | #EFECE6 / #E9E4DB | 低饱和衬托 |
| 选中高亮 | 青绿 #0F9D8A 自发光描边 | 与 UI 主色一致 |
| 网格/吸附点 | 青绿 30% 透明度 | 整理模式 |
| 线缆功能色 | 电源 #E5484D / 网线 #3B82F6 / 数据 #8B5CF6 / 充电 #F59E0B | 场景与图例同色 |

### 5.3 字体

- 字族：`Inter, "HarmonyOS Sans SC", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`；数字用 `font-variant-numeric: tabular-nums`。
- 字号/字重：24/600 入口标题；20/600 页面标题；16/600 面板标题；14/400 正文与控件；13/400 表格与属性行；12/400 辅助说明。
- 行高：标题 1.3，正文 1.5。

### 5.4 间距（4px 基准）

| 场景 | 值 |
|---|---|
| 图标与文字间 | 6px |
| 控件内边距 | 8×12px |
| 面板内边距 | 12px |
| 面板内分组间距 | 16px |
| 面板/卡片之间 | 12px |
| 页面边距 | 24px |
| 3D 视口内浮层安全边距 | 16px |

### 5.5 圆角

`--radius-sm 6px`（徽标/小控件）、`--radius-md 8px`（按钮/输入框）、`--radius-lg 12px`（卡片/面板/视口容器）、`pill 999px`（分段控件/标签）。

### 5.6 阴影

| 令牌 | 值 | 用途 |
|---|---|---|
| shadow-xs | `0 1px 2px rgba(20,22,26,.06)` | 输入框、小控件 |
| shadow-sm | `0 1px 3px rgba(20,22,26,.08), 0 1px 2px rgba(20,22,26,.04)` | 卡片、工具栏 |
| shadow-md | `0 4px 12px rgba(20,22,26,.10)` | 悬浮面板、下拉菜单 |
| shadow-overlay | `0 12px 32px rgba(20,22,26,.16)` | 对话框、抽屉 |

### 5.7 状态色使用规则

- 成功/完成：图标 + `--success` 文字，不整行着色。
- 进行中：细进度条/旋转图标用 `--primary`；文案给出阶段名（如「正在生成第 3/5 个模型」）。
- 警告/部分成功：整条 Banner 用 `--warning` 12% 底 + 文字；不使用红色。
- 失败：`--danger` 文字 + 描边按钮「重试」；错误原因一行内说明。
- 禁用：`--faint-foreground` + 60% 透明度，可附 tooltip 说明原因。

- `SceneModeLayer`（整理网格层 / 走线通道层 按模式挂载）
- `SelectionOutline`、`DragSnapController`、`CablePathEditor`
- `SceneLoadingOverlay`（场景加载进度 + 降级提示）

## 7. 关键交互约定

- **快捷键**：`1/2` 切模式；`Ctrl+Z / Ctrl+Shift+Z` 撤销/重做；`F` 重置视角；`Del` 删除选中；`Esc` 取消当前拖拽/取消选中。
- **撤销/重做边界**：快照 `{items, cables}`，合并高频操作（拖动 300ms 合并），上限 50 步；空间配置与识别确认不入工作台历史栈。
- **吸附规则**：摆放置位吸附 5cm 网格与桌缘/书架背板；走线吸附通道节点 6cm 半径。
- **整理度**（本地计算，标注「计算值」）：越界、悬空、遮挡重要设备、线缆交叉数、通道利用率 加权 0–100，可点开明细。
- **走线长度**：路径折线长度 + 8% 余量，向上取整 5cm；演示模式为折线估算，接口预留 `calculateCableLength()` 以便替换真实算法。
- **演示数据标识**：任何来自 `mock` 的数值/文案在就地位置显示灰色「模拟」小标；页面级演示项目右上角常驻「演示模式」徽标；「未接入」能力（如真实支付/云端）用虚线描边按钮 + 禁用 tooltip。

## 8. 状态设计

### 8.1 空状态

| 位置 | 文案与操作 |
|---|---|
| 最近项目为空 | 「还没有项目」+ 主按钮「创建项目」+ 次按钮「打开演示项目」 |
| 左面板无物品 | 「暂无物品」+「上传桌面照片」/「载入演示物品库」 |
| 照片页未上传 | 拖拽区文案 +「跳过，使用演示物品库」 |
| 属性面板未选中 | 「在场景或左侧列表中选择一个对象」 |
| 交付页步骤为空 | 「完成工作台整理后生成步骤」（附「返回工作台」按钮） |

统一结构：线性图标（40px，`--faint-foreground`）+ 一句话说明 + 1 主 1 次操作按钮。

### 8.2 加载

- 列表/面板：骨架屏（3–5 行），不用全屏 spinner。
- 识别/生成/导出：`ProgressPanel`，显示整体百分比 + 当前阶段名 + 分项列表；>10s 追加「仍在处理，可离开此页，任务将在后台继续」。
- 3D 场景：`SceneLoadingOverlay` 带进度与当前加载资源名；超时降级为占位盒渲染并提示。

### 8.3 失败

- 局部失败不阻塞页面：失败项就地红字 +「重试」+ 「跳过」。
- 页面级失败：`ErrorState` 居中卡片，含原因一句话、错误码（可折叠详情）、主按钮「重试」、次按钮「返回上一步」。
- AI 资产生成失败：默认自动降级为占位盒，提示「已使用占位模型，可稍后重试生成」。

### 8.4 部分成功

- 顶部 `PartialSuccessBanner`（琥珀）：如「5 个物品：3 个生成成功，2 个使用占位」。
- Banner 内操作：逐项重试 / 全部重试 / 继续使用占位。
- 交付页导出部分成功：导出可下载，缺失项在文档中标记「待补充」。

### 8.5 数据来源三态

| 标签 | 样式 | 含义 |
|---|---|---|
| 模拟 | 灰色描边 pill「模拟」 | 演示/占位数据 |
| 计算值 | 无 pill，数值后缀「≈」+ tooltip 说明算法 | 本地真实计算（整理度、长度） |
| 未接入 | 虚线描边 + 禁用 + tooltip「服务未接入」 | 后端能力未就绪 |

## 9. 技术基线（下一阶段锁定）

- React 18 + TypeScript + Vite 5；React Router 6；Tailwind CSS 3.4 + shadcn/ui；Zustand（+ persist）。
- three + @react-three/fiber 8 + @react-three/drei 9（互相兼容的 8.x/9.x 稳定线）。
- 服务适配层：`src/services/types.ts` 定义 `RecognitionService / AssetService / ExportService` 接口；`src/services/mock/*` 与 `src/services/http/*` 两套实现；`VITE_SERVICE_MODE=demo|api` 切换；密钥仅存在于后端（Rodin 等经应用后端代理，前端不持有）。
- 状态划分：`projectStore`、`spaceStore`、`itemsStore`、`cableStore`、`historyStore`、`taskStore`、`uiStore`（模式/视角/选中/对比）。
- 持久化：项目草稿全量本地持久化（IndexedDB 存照片与模型文件，localStorage 存元数据）。
