# 三维场景显示与性能（2026-10-18）

工作台、空间配置、方案对比与指南共用日光照明和渲染配置；独立接口描点、算法查看器及配件预览也请求高性能 WebGL 上下文并按需绘制。显示层调整采用浅木桌面、雾白柜体、浅灰蓝地面与低饱和物品配色。墙面从外侧观察时不遮挡室内，实际房间碰撞和算法边界仍由原几何定义。

## GPU 与绘制预算

- Three.js 本来就通过 WebGL 使用 GPU；`powerPreference: high-performance` 请求浏览器优先选择高性能图形设备，不能保证独立显卡被启用，也不能覆盖浏览器或系统的硬件加速设置。产品不添加强制显卡、忽略 GPU 黑名单或软件渲染启动参数。
- 七个 Canvas 均使用 `frameloop: demand`。相机操作、拖拽、模型加载和会话动画触发绘制；抽屉的命令式运动通过状态订阅唤醒画布。配件小预览取消常驻自动旋转，可手动查看。
- DPR 上限为 1.5；粗指针设备为 1.25。使用抗锯齿、不透明画布，关闭未使用的模板缓冲。统一 sRGB 输出和 ACES 色调映射。
- 房间相机裁剪范围为 0.1–30m；独立物品和小配件按各自尺度取景。主场景只用一盏投射阴影的灯，1024² 软阴影贴图，配置微小深度/法线偏移并配合无阴影补光，减轻自阴影条纹。
- WebGL 检测匹配当前 Three r169 所需的 WebGL2，结果缓存并释放检测上下文；不支持时保留既有降级提示。

## 闪烁修复

`furnitureAppearance.ts` 只处理明确的无纹理轴对齐箱体。加载时按同向平面分组，用矩形差集裁掉不同板件重复的共面部分；弧面与其他细节继续使用原网格。床架剖切组和常驻家具分别处理，三个抽屉各自处理，避免一个部件隐藏或移动后暴露缺面。GLB 自带的实心桌板按模型原样显示，不再叠一层穿孔桌面，只有模型加载失败时才回退到简化家具。

处理发生在显示副本上，不写回 `Prefabmodel/`、`objects/` 或 public GLB，不改变碰撞数据、支撑面、物品位姿、接口或规划结果。加载过程只执行一次；重新进入预览时按新实例处理。合拢笔记本只移除已确认的重复 primitive，保留一份有效几何。

透明辅助层不写入深度，选中线框略大于物品边界，减少与实体表面的争抢。原始灰模物品在加载后着色，显示器在原有面上使用顶点颜色区分屏幕，不增加共面贴片。

鼠标垫、显示器底座和手机还有独立的资产问题：闭合壳体的三角面朝内，上表面被背面剔除，朝上的底面又与桌面重合。`meshWinding.ts` 在这三种预制件加载时按连通壳体检查有向体积，只反转闭合、边连接一致且朝内的壳体；显示器其余正确部分、开放薄片和非流形部分保持原样。处理克隆的显示几何索引并重算法线，不抬高物体，也不改变顶点位置、包围盒、碰撞或源 GLB。结果随模板缓存，不参与逐帧计算。

- [x] 手机贴桌预览破碎条纹与视角移动闪烁：已解决（2026-10-18，用户确认）。手机追加修正 96 个三角面，可见上表面从 0m 恢复为 0.007m；修复前浏览器回归命中桌面高度并失败，修复后手机完全置于桌面内，中心及四角在五组视角与桌面遮挡对照中通过，鼠标垫和底座同时回归通过。类型检查与生产构建通过；本轮证据在 `.work/phone-contact/`。

## 交互计算

物品的抽屉归属按位姿和房间引用缓存；不在抽屉内的物品不再每帧重写位置。线缆收拢时，未变化的目标曲线采样单独缓存，动画帧只计算插值；后端已验证的采样点和路径长度保持原语义。未将布局、碰撞或走线校验迁移到 GPU。

静态预制键盘和鼠标在加载时按材质与顶点格式合批，先将节点变换烘焙进显示几何，再合并绘制；镜像、蒙皮及变形节点跳过。真实键盘网格从 93 个合为 5 个，鼠标从 31 个合为 5 个，分别保留 14,520 与 47,404 个三角面；另以 588 条射线复核两者可见表面。不改算法碰撞或接口坐标。其他物品、独立抽屉和床架剖切节点保持原结构。
