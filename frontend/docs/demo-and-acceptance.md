# 演示与验收说明（一键演示 · 流程检查 · 能力边界）

对应交付轮次：**演示与验收收尾 + 工作台阶段复检与路演打磨**（2026-10-17，0.4.0）。本文档是演示操作、验收结论与后续接入位置的单一口径，运行命令的权威说明仍以 [../README.md](../README.md) 为准，仓库字段与坐标约定以 [数据契约](../../docs/data_contract.md) 为准。

---

## 1. 启动方式

```bash
cd frontend
npm install          # 首次；Node.js ≥ 18（验证使用 Node 24 / npm 11），依赖版本已固定
npm run dev          # http://localhost:5173
```

检查命令（可重复执行）：

```bash
npm run typecheck    # tsc --noEmit
npm run build        # tsc --noEmit && vite build
```

- 默认 `VITE_SERVICE_MODE=mock`：识别 / 模型生成 / 布局与走线规划**全部为本地模拟与规则计算**，不调用任何外部接口。
- 切换 `service` 模式仅为联调占位（`api/http` 桩，未接入时抛错），演示与验收**不需要**后端与网络。
- Rodin 等第三方凭证只在后端持有；前端不配置、不直接调用供应商接口。

## 2. 演示操作顺序

### 2.1 一键演示（推荐，6 步导览）

1. 首页点「**一键演示**」（会自动重置示例项目并进入导览第 1 步）。
2. 按右下角「演示导览」卡片逐步操作（可「下一步 / 上一步 / 点步骤条跳转」，完成操作后自动打勾）：

| 步骤 | 页面 | 建议操作 | 完成判定 |
| --- | --- | --- | --- |
| ① 查看凌乱桌面 | 工作台 | 幕一：进入时自动切到桌面视角，观察物品重叠与散乱线缆（底部有校验警示） | 点「下一步」即完成 |
| ② 确认识别物品 | 照片导入 | 核对物品清单；可「直接查看 3D 资产」，或运行一次模拟识别（含「强制模拟识别失败」→ 重试） | 进入「③ 生成 3D 资产」 |
| ③ 自动整理 | 工作台 | 幕二：「生成整理方案」→ 播放整理动画 / 查看整理前·后对比 →「接受方案」 | 接受方案 |
| ④ 规划走线 | 工作台 | 切到「规划走线」→ 顶部「规划走线」按钮 | 全部线缆由演示规则规划完成 |
| ⑤ 对比前后 | 工作台 | 幕三：左侧「收拢动画（全部线缆）」看原始 → 建议过渡（可暂停 / 跳过 / 重播）；或选中线缆切换「原始 / 建议」 | 切换对比视图或播放收拢动画 |
| ⑥ 查看执行指南 | 方案交付 | 勾选步骤、预览配件参数、导出 JSON / PNG 或打印 PDF | 进入页面即完成 |

3. 结束：「完成演示 🎉」后可「**重置并重播**」（重新种入示例项目、清空交付勾选 / 候选方案 / 任务记录 / 撤销历史，回到凌乱初始态）或退出自由探索。
4. 导览进度持久化：刷新页面后导览从当前步骤继续。

### 2.2 演示辅助开关

- **跳过模拟等待（演示加速）**：出现在照片导入页、工作台底部任务栏（有活动任务时）与导览卡片。开启后进行中的模拟等待立即结束、后续等待不再计时；仅影响本地模拟，`service` 模式下控件自动隐藏。
- **减少动态效果**：系统开启 `prefers-reduced-motion` 后，整理动画与线缆收拢动画直接显示末态（面板就地提示），不做分批 / 插值动画。
- **失败 / 重试演示**：导入页勾选「强制模拟识别失败」；模型生成中「台灯」首次必定失败（重试后成功）；走线规则规划可能产生 conflict 线缆（路径检查给出障碍原因）。

### 2.3 手动完整流程（不使用导览）

首页「创建项目」→ 空间配置（改尺寸并实时预览）→ 照片导入（示例照片 / 上传 / 跳过识别）→ 物品确认（改尺寸、补物品、删误识别）→ 3D 资产（生成 / 失败重试 / 使用占位盒）→ 工作台（整理 + 走线）→ 方案交付（勾选 + 导出）。

### 2.4 路演三幕（重点画面 · 可重复播放）

三个画面即导览的第 1 / 3 / 5 步，进入工作台步骤时相机自动切到桌面视角（`workspaceStore.applyViewPreset`，重复进入同一预设也会重新应用）：

1. **幕一 · 杂乱还原**：打开示例项目即未整理初始状态（物品重叠、线缆松散下垂并互相交错，底部有摆放校验提示）。「重置并重播」可随时回到这个画面。
2. **幕二 · 归位动画**：整理模式 →「生成整理方案」→「播放整理动画」（按物品组分批归位，可暂停 / 跳过 / 重播）→「整理前后对比」一键切换 →「接受方案」。
3. **幕三 · 收拢对比**：走线模式 →「规划全部走线（演示）」→ 左侧「收拢动画（全部线缆）」播放「原始 → 建议」过渡（可暂停 / 跳过）；或用「原始 / 建议」分段控件即时切换。

串成完整流程：首页「一键演示」→ 依次完成三幕 →「查看执行指南」；结束后「重置并重播」可原样重复整段流程（示例项目、整理前快照、候选方案、任务记录与勾选全部回到初始）。

## 3. 已实现功能清单（本轮验收范围）

- **一键演示导览**：6 步固定顺序、自动导航、完成检测（页面信号 + 数据兜底）、步骤条跳转、进度持久化、「重置并重播」、演示模式标识常驻（导览卡 / 顶栏 / 工作台 / 项目卡）；工作台步骤自动切换桌面视角，对应路演三幕（杂乱还原 / 归位动画 / 收拢对比）。
- **演示加速**：「跳过模拟等待」全局开关（`lib/mockPacing` 统一承载全部 mock 等待，可唤醒进行中的等待）。
- **减少动态效果**：整理动画、线缆收拢动画遵循系统偏好；面板提示当前生效方式。
- **整理前状态**：进入工作台自动采集快照；接受方案后可「**恢复整理前状态**」（可撤销）或「重新采集」。
- **照片导入**：示例照片、拖拽 / 选择上传（IndexedDB）、格式 / 大小 / 数量校验、写入失败可重试提示、识别状态条（等待 / 分析中 / 待确认 / 完成 / 失败）、失败重试、物品增删改与尺寸确认（估计值 → 确认值）。
- **模型生成队列**：等待 / 生成中 / 完成 / 失败 / 部分成功，逐件重试与「使用占位盒」；失败不阻塞进入工作台。
- **三维工作台**：拖拽吸附（释放时无效落点自动回退到上一次有效位置，不写入越界 / 相交数据）、旋转、撤销 / 重做（含快捷键）、摆放校验、视角预设、物品属性与模型状态面板。
- **空间整理**：规则式方案预览、分批动画（播放 / 暂停 / 跳过 / 重播）、整理前·后对比、接受 / 恢复、未放置说明与规则解释。
- **走线规划**：接口编辑、连线、路径节点（拖动 / 微调 / 增删 / 排序）、平滑路径障碍检查、线长估算与不足提示、原始 / 建议对比、收拢动画、设备移动后「需重算」与一键更新；左侧列表「收拢动画（全部线缆）」一键播放原始 → 建议过渡（可暂停 / 跳过 / 重播）。
- **方案交付（执行指南）**：见 [上一轮记录](../CHANGELOG.md)（截图 / 勾选 / 配件 / 问题清单 / JSON / PNG / 打印版式）。
- **降级与空态**：工作台、交付页、空间配置预览三处 WebGL 检测与可操作降级；空项目、项目不存在、无物品 / 无线缆均有空态说明。

## 4. 模拟能力与真实能力清单

| 能力 | 当前（演示模式） | 真实性说明 | 真实实现位置 |
| --- | --- | --- | --- |
| 照片识别 | 本地模拟：固定 9 项物品 + 低置信度与失败注入 | 非真实视觉模型；界面标注「模拟」 | `api/` 对接后端识别服务 |
| 模型生成 | 本地模拟：延时 + 固定失败规则，产出占位几何 | 不生成真实 3D 资产、不调用 Rodin | `api/` → 后端代理 Rodin |
| 空间整理 | 浏览器内规则计算（三区落位、相交校验） | 真实本地计算，但为可解释规则，非优化算法 | `OrganizationPlanningService` 接口 → 布局算法 / 后端 |
| 走线规划 | 浏览器内规则规划 + 几何采样检查 | 非寻路算法（无 A* 等），`algorithmVerified=false` | `CablePlanningService` 接口 → 走线算法服务 |
| 线长 / 占地面积等数值 | 由当前几何实时计算 | 计算值（非实测），口径就地标注 | 保留 |
| 配件几何 / GLB 导出 | 参数化外观预览；GLB 为真实导出 | 非水密、不可直接打印；STL 未接入 | 需封闭几何生成能力（布尔合并） |
| 交付页步骤与配件估算 | 由当前方案数据实时推导 | 非写死演示步骤 | 保留（数据来源已在界面标注） |
| 数据持久化 | 浏览器 localStorage / IndexedDB | 本机数据，清浏览器存储即丢失 | 后端服务接入后迁移 |

演示模式标识体系：`演示数据` / `模拟` / `计算值` / `未接入`（`ui/kit/data-badge.tsx`），全流程就地标注，不把模拟结果展示为真实算法结论。

## 5. 后续接入识别、Rodin 与规划服务的位置

1. **服务契约**：`frontend/src/api/types.ts` 定义 `AppServices`（recognition / modelGeneration / layoutPlanning / cablePlanning / organizationPlanning）。
2. **模式切换**：`frontend/src/api/index.ts` 按 `VITE_SERVICE_MODE` 选择实现；`mock` = 本地模拟，`service` = `api/http/` 调用应用后端（当前为桩，未接入抛 `ServiceNotImplementedError`）。
3. **后端接入点**：
   - 识别：实现 `RecognitionService.recognize`（照片以 `photoId` 引用 IndexedDB 文件，联调时改为上传）。
   - Rodin 生成：实现 `ModelGenerationService.generateObject`（后端异步任务 + 轮询 / 回调；产物写回 `ModelRef`，实时任务转到 `未接入` 标注的缺口）。
   - 布局 / 走线：实现 `OrganizationPlanningService` / `CablePlanningService` / `LayoutPlanningService`（算法服务返回契约字段，UI 已预留 `algorithmVerified` 等标注位）。
4. **契约差异**：6 项已知差异（原点 / 演示尺寸 / 命名 / 字段 / 状态语义 / 算法来源）见 [../README.md](../README.md)，约定在 `api/` 层转换，不直接以内部模型充当 wire format。
5. **凭证边界**：Rodin 等第三方密钥只在后端；前端不读取、不直连。

## 6. 工作台阶段复检（第 04 阶段：三维选择 / 拖拽 / 属性同步 / 保存）

复检对象：整理、走线、方案导出共同依赖的三维工作台数据层。结论口径同上（代码路径 + 构建 / 状态层冒烟验证；交互项为手动验证）。

| 完成标准（任务清单口径） | 结论 | 说明与依据 |
| --- | --- | --- |
| 相机 360° 旋转缩放、物品选择、鼠标左键桌面拖动、旋转和数值编辑 | 通过 | 轨道相机 + 6 个视角预设；点击选中 / 空白取消；拖拽吸附支撑面（桌面 / 书架搁板 / 地面，10mm 网格）；Q/E 与方向键微调；属性面板毫米制数值编辑。 |
| 无效拖动恢复到上一次有效状态 | **本轮修复** | 此前松手会提交无效落点（越界 / 相交仍写入数据）；现在无效落点回退到本次拖拽中最后一次有效预览位置，从未有效则不提交（纯函数 `frontend/src/scene/dragCommit.ts`，冒烟覆盖 6 种情形）。 |
| 保存（持久化） | 通过 | 属性 / 位置变更经 `workspaceStore` 提交后写入 localStorage（`dormtopology.projects`）；冒烟断言序列化内容包含更新后的名称与位置。 |
| 移动 / 旋转后相关线缆失效 | 通过 | 位置 / 旋转 / 接口变化 → 引用设备的线缆标记「需重算」；撤销时随同一历史快照还原。冒烟断言 3 条引用线缆的标记与还原。 |
| 撤销 / 重做 | 通过 | 一次拖拽 = 一次可撤销记录；无效落点与无变化拖动不产生历史。冒烟覆盖提交 → 撤销 → 重做的完整时间线。 |

## 8. 剩余限制（如实声明）

- 无自动化浏览器 E2E：以上交互项依赖手动验证；本仓库环境仅能跑类型检查 / 构建 / 状态层冒烟（见验证记录）。
- 走线为规则式演示（非寻路算法），整理为可解释规则（非优化算法）；均未经真实算法验证。
- 候选方案对比 UI 未实现（工作台按钮禁用标注「后续阶段」；已保存方案保留）。
- 配件几何为外观预览，不可直接打印；STL 未接入（需封闭几何 / 布尔合并能力）。
- 手机端上传、预览与场景查看未做实测记录。
- 演示加速与减少动态均为本机行为开关，不影响真实服务接入后的交互。
