# DormTopology 3D 研发任务与验收

本文追踪待实现任务，当前复选框均未验收。范围、工期与职责以[实施方案](implementation_roadmap.md)为准，模块数据以[数据契约](data_contract.md)为准，交互见[用户体验设计](ux_design.md)。

## 1. 共同前置任务（H0–H4）

负责人：A、B、C 共同确认；数据契约变更由三方同步。

- [ ] 确认场景单位、坐标轴、原点、底面中心锚点和旋转约定。
- [ ] 按数据契约制作场景、整理结果和走线结果样例，验证字段、ID 引用与错误状态。
- [ ] 建立一个演示场景：8 件简化物品、3 根线、桌面与书架可放置区域、碰撞体和禁入区。
- [ ] 配置真实存在的穿线孔；背板后通道作为后续扩展，未实现的策略必须返回不可用。
- [ ] 明确原始快照、当前场景和规划结果的版本；拒绝将旧版本结果覆盖到新场景。

## 2. 成员 A：3D 前端

依赖：共同数据契约；先接 Mock，最终必须通过真实后端与算法联调。

- [ ] 建立 Web 界面、照片上传与预览；摄像头入口可选。
- [ ] 支持照片框选补标、物品增删、尺寸与来源确认、原始位置校正。
- [ ] 创建参数化桌面与书架，支持相机控制、物品选择、拖动、旋转和数值编辑。
- [ ] 保存经用户确认的原始快照；无效拖动恢复到上一次有效状态。
- [ ] 实现按物品 ID 替换显示模型的导入流程，保留变换、碰撞体和接口。
- [ ] 提供手动接口取点、连接确认、线长与线径编辑，使用首版穿线孔策略。
- [ ] 提供一个预设 4 位插排、独立插孔选择及墙插/网口的墙面内位置编辑。
- [ ] 展示生成、规划、失败与缓存状态；物品移动后使相关线缆和旧指南失效。
- [ ] 展示前后对比、归位动画及与有效场景对应的执行指南，允许导出指南。

验收：

- [ ] 电脑浏览器能完成完整编辑流程，手机浏览器可查看场景和结果。
- [ ] 框选、物品拖动与相机操作互不误触；数值编辑可用于精确定位。
- [ ] 模型异步替换后，已有物品位置、尺寸、接口和线缆连接关系保持一致。
- [ ] 切换前后状态不修改原始快照；缓存资产与实时生成资产有可见区别。
- [ ] 真实整理和走线结果可以驱动场景；只有 Mock 成功不能标记本模块完成。

## 3. 成员 B：识别与生成后端

依赖：共同数据契约、测试图片、服务凭证与账户配额。服务不可用时实现明确失败响应，不把 Mock 计为真实接入。

- [ ] 处理图片上传、检测框和单件裁剪，输出 6–10 件物品的候选清单，允许用户校正。
- [ ] 为场景、物品与接口分配稳定 ID；保存尺寸来源、原始快照和当前场景版本。
- [ ] 封装 Rodin 适配器，实测并记录所选 API 的版本、提交/查询/下载接口及任务字段。
- [ ] 保存内部任务与供应商任务标识，支持排队、生成中、完成、失败状态。
- [ ] 处理限流、超时、失败和重试；同图同参数复用缓存并返回来源标记。
- [ ] 下载并校正 GLB 的尺寸、锚点、轴向；任务结果按物品 ID 交付前端。
- [ ] 根据最终场景与规划结果生成执行指南；旧版本结果和未解决问题必须显式处理。
- [ ] 凭证只在后端使用，不进入前端包、模型元数据或日志。

验收：

- [ ] 一张测试照片能进入可编辑物品清单；漏检和误检可修正。
- [ ] 至少一次真实 Rodin 任务完成提交、查询、下载及前端替换，记录实际耗时与参数。
- [ ] 至少 1 件真实资产生成成功；模拟失败或超时不阻塞简化场景的整理与走线。
- [ ] 重试不会无意重复提交同一在途任务，缓存命中可追溯。
- [ ] 指南中的物品、连接和路径与当前有效结果一致；失效或失败部分不被描述为已完成。

## 4. 成员 C：布局与走线算法

依赖：共同场景数据；先用简化碰撞体，不等待 Rodin 外观资产。

- [ ] 实现桌面和书架多平面摆放，限制为 0°/90° 朝向，不做自由堆叠。
- [ ] 校验边界、碰撞、支撑、层高、固定物品与操作保留区域。
- [ ] 按使用频率、连续操作面积和搬动成本等目标贪心摆放，首版只生成一个布局。
- [ ] 无处摆放的物品保留原位并返回原因；不通过删除物品制造成功结果。
- [ ] 建立接口、桌沿、穿线孔、线槽与立柱固定点构成的可走线网络。
- [ ] 按接口类型和插孔占用情况检查连接；用 A* 或 Dijkstra 搜索路径。
- [ ] 校验线径净空、线长、余量、弯曲半径与禁入区；失败时提示用户调整，不自动循环重排。
- [ ] 平滑后复查碰撞、长度和弯曲条件，失败时尝试其他路径或返回失败；不能将尖角折线作为可执行线缆。
- [ ] 物品、接口、插排或障碍物变化后，重新验证受影响的结果。
- [ ] 用同一规则计算整理前后的连续可用面积、桌面暴露线长和未解决冲突数。

验收：

- [ ] 正常场景整理后，已放置物品满足全部硬约束；固定物品不移动。
- [ ] 空间不足时返回部分成功或不可行，未安放物品仍存在于场景中。
- [ ] 穿线孔策略使用实际开孔通道；未实现背板策略或无通道时返回明确失败。
- [ ] 覆盖线长不足、接口遮挡、通道过窄、插孔占用和不兼容接口案例，均不输出有效路径。
- [ ] 输出路径包含真实端点，平滑后仍满足约束；移动或旋转设备后接口世界坐标正确更新。
- [ ] 超出走线路径尝试数量上限时终止并说明失败，不无限重试。

## 5. 可选资产美化（核心闭环完成后，A 主责，C 核验几何）

- [ ] 检查 `objects/dorm_desk.blend`、纸巾盒和杯子 OBJ 的实际尺寸、轴向与锚点，记录核验结果。
- [ ] 按数据契约导出 `models/dorm_desk.glb` 及单品 GLB，检查材质、法线和浏览器显示。
- [ ] 对齐桌体网格与场景中的碰撞体、支撑面和穿线孔；背板通道仅在后续实现时核验。
- [ ] 验证导入模型与简化几何使用相同单位和坐标，不重复旋转或缩放。

这些 GLB 当前尚未入库；`models/` 是待生成的交付目录，不是已有资源。48 小时版允许全程使用参数化桌体与简化几何；上面的资产美化任务不作为首版阻塞项。至少 1 件真实 Rodin 模型的导入仍是必需验收项。

## 6. 集成与路演（H28–H48，三人共同验收）

- [ ] 8 件物品、3 根线完成“照片确认 → 整理 → 接线 → 走线 → 对比 → 导出指南”。
- [ ] 任意一次场景变更使旧规划失效；旧异步结果不覆盖新场景，旧指南不能继续显示为有效。
- [ ] Rodin 失败、识别失败和不可行规划均有可操作的恢复路径。
- [ ] 页面刷新后可恢复已保存的场景、原始快照和生成任务状态。
- [ ] 在目标电脑检查完整流程、手机检查查看能力，记录加载耗时与交互性能。
- [ ] 明确标注预缓存资产与实时生成任务，演示入口可查看真实任务状态。
- [ ] 保存正常案例及上述失败案例的输入、结果与验收记录。

48 小时是首版交付硬约束，各角色按实施方案并行推进。超时按实施方案降级，未通过的核心验收必须如实标为未完成。背板策略、插排规格选择、完整手机编辑、抽屉、AR、打印和刚体玩法另开后续任务。
