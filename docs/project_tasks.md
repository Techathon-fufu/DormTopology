# DormTopology 3D 研发任务与验收标准清单 (tasks.md)

---

## 模块一：杂物分拣与三维装箱系统 (算法/逻辑)
> **核心目标**：接收用户上传的照片，识别物品并计算出合理的收纳目标落位数据，输出单品资产与坐标。

### 最基本要求
1. **多模态目标识别**：接收前端传入的桌面照片，调用视觉大模型输出物品名称列表，并区分“常用外设（保留在桌面）”与“散落杂物（需收纳）”；
2. **单品模型导出与尺寸估计**：针对识别出的物体，提取/生成对应的小模型资产（GLB 格式），供模块三动态加载；
3. **基础装箱落位规则**：
   - 键盘、鼠标、数位板保留在主桌面中央区域；
   - 课本、水杯、收纳盒等杂物分配至上层四格书架或右侧抽屉内；
   - 保证物品放置在柜格内，彼此不重叠；
4. **数据格式化导出**：输出一个标准的 `packing_result.json`，记录每个物品的名字、模型路径、整理前坐标与整理后目标坐标 `[x, y, z]`，交由模块三前端读取。

### 验收标准
- [ ] 接收一张测试照片，能成功跑出识别后的物品清单；
- [ ] 能提供至少 1~2 个独立的小模型 GLB 文件供前端加载测试；
- [ ] 算出的目标坐标落在书架或抽屉的物理容积范围内，无明显穿模；
- [ ] 导出的 `packing_result.json` 格式符合约定，能被模块三前端正常解析。

## 模块二：智能走线与电线避障路由 (算法/逻辑)
> **核心目标**：接收用户手动选取的设备端点与终点坐标，按粗/细线材分类，生成贴墙收拢的电线路径数据。

### 最基本要求
1. **端点坐标接收**：
   - 接收前端传入的手动接线起点坐标 `[x, y, z]`（用户点击物品表面任意点）与终点坐标（插排孔位或离地 30cm 的墙插/网口）；
2. **线材类型支持**：
   - 区分**粗线**（台式机/显示器电源线、网线、插排总线）与**细线**（充电线、外设连接线），分配不同的线径参数与弯曲度；
3. **支持两种走线模式**：
   - **模式一（走过线孔）**：线缆经桌面后部过线孔穿下，便于设备移动和日常插拔；
   - **模式二（走背板后）**：线缆绕至背板后方下行，隐蔽美观但移动稍受限；
4. **支持内置插排 (PDU) 逻辑**：
   - 引入插排概念，支持不同孔位数量（如 4/6/8 位）的插孔分配与多线缆汇聚走线；
5. **数据格式化导出**：输出 `cable_routing.json`，包含每根线的控制点坐标序列 `[[x, y, z], ...]`、线材粗细属性（thick/thin）及走线模式标识，供模块三渲染。

### 验收标准
- [ ] 接收任意两点坐标，能成功生成符合桌面避障规则的三维样条曲线路由；
- [ ] 能区分并输出粗线与细线的线径属性；
- [ ] 能根据参数分别输出“走过线孔”与“走背板后”两种不同路径；
- [ ] 导出的 `cable_routing.json` 格式符合约定，能被模块三前端正常解析。

## 模块三：Web 平台、视口渲染与交互接口 (前端/平台)
> **核心目标**：负责整个前端界面的搭建、3D 视口渲染、物体鼠标拖拽交互，并预留好模块一和模块二的输入提交与小模型导入接口。

### 最基本要求
1. **拍照上传与手动补标界面**：
   - 网页端提供拍照/上传桌面照片组件与预览图；
   - **手动框选补标**：允许用户在照片上对未识别的杂物手动拉框标记，预留选区对接 Rodin Agentic API 生成 3D 资产；
2. **Web3D 视口加载与桌面物品拖拽交互**：
   - 使用 Three.js 加载 `models/dorm_desk_assembled.glb`，支持视角 360° 旋转缩放；
   - **桌面物品拖动**：支持鼠标左键拖拽桌上物品并在桌面上滑动；
   - **墙面网口与插座位置调节**：在场景中呈现离地 30cm 的网口和双孔插座面板，**允许用户在 Y 轴上自由调整二者位置**，并将更新后的坐标传给走线模块；
3. **手动点选接线与线材分类交互**：
   - **手动点选起点**：支持用户用鼠标在任意物品表面点击任意一点作为接线起点；
   - **线材分类选择**：提供“粗线（电源线/网线）”与“细线（充电线）”的切换选择；
   - **终点连接**：点击插排孔位或墙插作为终点，将两点及线材属性传给走线接口并渲染为 3D 曲线（粗线与细线赋予不同粗细渲染）；
4. **内置插排 (PDU) 快速选择与配置**：
   - 提供快捷选择面板，供用户选择不同孔位数量的插排（如 4/6/8 口），并可在场景中自由放置；
5. **预留动态导入小模型的接口 (含 Rodin 资产)**：
   - 编写 `importModel(url, name, position)` 函数接口，支持动态把外部小模型（GLB 格式，如 Rodin 产出）加载进桌面场景，并自动附加鼠标拖拽能力；
6. **预留模块一与模块二的操作按钮与接口**：
   - 界面预留【✨ 智能收纳】按钮，留出接收 `packing_result.json` 的标准接口函数；
   - 界面预留【⚡ 智能布线】按钮（含“走过线孔”与“走背板后”模式切换），留出接收 `cable_routing.json` 的标准接口函数；
   - 编写本地 Mock 测试数据，确保前端收到数据时能打印控制台日志或触发简单的占位动效。

### 验收标准
- [ ] 网页在电脑和手机浏览器中流畅运行，支持图片上传与本地预览；
- [ ] **支持在照片上拉框手动标记漏检杂物**；
- [ ] 3D 画布能正常加载场景，桌上物品支持鼠标拖拽平移；
- [ ] **支持鼠标在物品表面任意点击取点并连线至插排/墙插，且能选择粗线/细线**；
- [ ] **网口与插座面板可在场景中沿 Y 轴自由调节位置**；
- [ ] **提供插排规格选择（不同孔位）并支持在场景中放置**；
- [ ] **提供动态导入小模型接口 `importModel`**，外部模型加载后可被拖动；
- [ ] 界面上有“智能收纳”与“智能布线”（含走线模式切换）按钮，预留接口均可调通 Mock 数据。
