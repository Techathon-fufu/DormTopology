# DormTopology 3D 用户体验设计

本文只定义首版用户流程与交互状态。功能边界和工期见[实施方案](implementation_roadmap.md)，字段及坐标见[数据契约](data_contract.md)，完成标准见[任务清单](project_tasks.md)。本文描述的是待实现体验。

## 1. 场景设置与照片上传

电脑端提供完整编辑流程，手机首版支持图片上传、本地预览以及场景和结果查看。用户选择标准桌面，确认桌宽、桌深和桌面高度，然后上传一张桌面照片；浏览器摄像头拍摄作为可选入口，不影响文件上传流程。最终视口加载 `models/dormdesk_body.glb`，支持 360° 旋转与缩放；开发阶段可使用参数化几何。

默认尺寸使用数据契约中的演示配置，界面以厘米展示；所有默认值都可编辑，并明确标注为示例值。照片不能替代实际测量。

上传后展示识别进度。图片格式不支持、上传失败或识别失败时保留可用输入，提供重试和手动添加物品入口。

## 2. 物品确认与简化孪生

- 在照片上显示检测框和对应物品列表，区分保留在桌面的常用外设与待收纳杂物；允许删除误检、修改类别、补充遗漏物品。
- 手动补标采用鼠标矩形框选，提供取消和重新框选操作；触屏编辑留待后续完善。
- 框选区域可提交给后端裁剪并对接 Rodin 生成，供应商接口和版本按真实账户核验；前端不持有凭证。
- 用户确认关键物品尺寸、使用频率、允许区域与固定状态；估计尺寸保留来源标记。
- 简化长方体或圆柱体先进入场景；用户通过俯视图和属性面板校正原始位置与朝向。
- 用户确认原始状态后保存对比快照。后续拖动修改当前状态，不隐式覆盖原始快照；重新建立基线需明确操作。

确认前的物品可以预览和编辑，尺寸未确认时禁用规划。原始线缆路径可在保存快照前选择性录入；未录入仍可继续，但原始暴露线长显示未知。后续补录不能悄悄改写旧快照，需要用户显式重建基线并接受对比起点改变。

首版对比的是用户确认后的场景快照与最终方案，不宣称照片到真实空间的精确自动重建。

## 3. Rodin 外观生成

用户至少选择 1 件有辨识度的物品提交真实生成，其余物品保留简化模型或使用明确标注的缓存。单件资产显示排队、生成中、完成或失败状态。操作期间，场景与简化模型继续可用。

完成后仅替换显示模型，保留物品 ID、位置、尺寸、碰撞体和接口。首次失败时保留简化模型，重新生成期间或失败后保留已有可用外观，显示原因并允许重试。缓存命中必须显示缓存来源，演示缓存与实时任务使用相同的模型导入流程。提交结果未知时提示可能已被供应商受理及重复计费风险，不自动重提；普通查询超时沿用原任务查询。

交付 1–2 个独立单品 GLB（至少 1 个），其中至少 1 件来自真实 Rodin 任务。提供 `importModel(url, name, position)` 导入接口，导入后注册稳定 ID 并可鼠标拖动；先作为待确认草稿，补齐规划字段并确认尺寸后才进入算法。异步外观替换按已有物品 ID 执行，不创建第二件物品。

不显示未经实测的固定完成倒计时，不承诺整桌物品在 30 秒内生成。

## 4. 推荐整理与手动调整

用户点击“智能收纳”，系统在桌面、上层四格书架和右侧抽屉分区中生成推荐布局。键盘、鼠标、数位板保留在主桌面中央，课本、水杯、收纳盒等进入经用户确认的书架格或抽屉区域。抽屉使用固定可访问状态，不要求开合交互。归位动画只展示状态变化，不作为真实搬动路线。

显示器和打印机等主要设备优先占用经确认的主视区或侧部设备区，再安排小物品；预览详情显示摆放优先级。直插适配器显示所属插孔，不能把与插排接触的外观当成有效插接；必须通过当前位姿与插孔占用检查。这些字段先在独立算法工作台展示，产品端编辑仍待接入。

- 成功：显示推荐布局及按统一规则计算的前后指标。
- 部分成功：列出无处安放的物品及原因；保留其当前位置，不把它们计为已收纳。
- 无可行方案：保留当前场景，说明冲突及可调整条件。

推荐结果先预览，用户选择接受或取消；预览及动画不写入正式场景、不增加版本。接受后由后端复核并保存，返回新版本才更新当前状态；取消保留原场景。预览期间出现编辑草稿或版本变化时禁止应用旧建议，提示重新规划。

用户可用鼠标左键在桌面上拖动物品、旋转物品，或在属性面板输入位置和尺寸。鼠标操作需区分选择、拖动和相机控制；尺寸与位置输入为精确调整入口。无效摆放应显示冲突并恢复到上一次有效状态。尺寸编辑使尺寸和接口待重新确认，单纯平移或旋转保留局部接口确认。所有编辑在后端保存成功后形成新版本，使旧走线与指南失效；检查当前布局后，由用户触发重新布线，首版重验全部请求线缆。保存失败保留草稿并提示重试，不将草稿冒充已保存场景。

首版采用几何约束检查；刚体反馈、自由堆叠和装箱游戏属于后续扩展。

## 5. 接线与路径规划

常用设备提供接口模板。用户进入接线模式后，可在任意物品表面任意点击取点或编辑接口位置，并确认接口类型、连接对象、线径和最小弯曲半径。走线规划不要求输入现有线长；成功后展示路径长度、预留及所需备线长度。已有数据提供现有线长时继续校验是否足够，未知时不列为缺失输入或声称长度充足。表面取点写入物品局部坐标，随物品移动和旋转更新。提供粗线/细线切换，加载不同线径与弯曲半径预设并允许确认修改，渲染粗细与实际线径一致。

用户选择起点与终点；可连接兼容的设备接口、插排孔位、墙插或网口。线材电气类型与粗细分开记录，粗细默认值仍需用户确认。提供 4/6/8 位插排规格选择，可在场景中放置并调整位置，各插孔独立选择；同一插孔不能被重复占用，多线缆可沿有足够净空的通道汇聚。切换规格后，提示用户重新指定被移除孔位上的连接，旧路径失效。

规格切换和改接先作为同一份草稿；仍有悬空接口时禁止保存和规划，取消恢复原规格及原连接。尺寸或接口修改后须完成重新确认；已引用但未确认的接口不能开始走线。

墙面呈现默认离地 0.30m 的网口与双孔插座面板，默认高度锚点以数据契约为准；允许在墙面内调整，左右对应 X，上下对应 Y，深度 Z 固定。必须支持沿 Y 轴调节并将新坐标传给走线模块。桌体、插排或面板位置改变后，相关路径必须重新验证。

实际走线还需确认承托和固定条件：桌沿、柜侧及孔边的固定位置，桌下已安装的扎带或集线托盘，以及最大无支撑跨距。预览显示支撑范围与已用固定件，明确区分“支撑已复查”和“支撑未评估”。跨距超限时提示补充固定件或调整路径，不显示有效连接；固定件调整保存后使旧走线和指南失效。这些能力已在独立算法验证入口展示，产品工作台的编辑、保存与指南串联仍待实现。

逐根走线完成后，可单独展示“集线槽建议”：共同收入的线缆、共用区段、占用/可用宽度和待安装位置。用户可以保留原逐线方案，推荐不能替代当前支撑状态。确认安装并保存后形成新版本再复查；独立算法入口只展示建议，不冒充已经安装或保存。

路径策略受场景几何约束：

- “走过线孔”：经场景中明确配置的穿线孔下行。
- “走背板后”：绕至背板后方，经具有足够净空的通道下行。

“智能布线”按钮提供以上两种策略切换，两种策略均须完成首版验收。缺少对应通道时禁用该策略并说明原因，同时记录该场景不具备该策略条件，不能以禁用代替演示场景双策略验收。规划中显示状态；成功后按已验证控制点和采样点绘制路径，线长不足、接口遮挡或无可行路径时显示具体原因，不能展示成功连线。规划采用路径搜索与平滑后复查，不能用样条动画替代避障验证。

部分成功时只绘制本次结果中 `valid` 的线缆，失败线显示原因并清除其旧路径，整体标为未完成；不能把历史有效线或失败线的空路径计为当前成功。任一当前线缆失败时，完整暴露总长显示未知，不展示改进比例。

“智能收纳”和“智能布线”分别接收数据契约中的两类 JSON 结果，并支持导出相应 JSON 文件。提供本地 Mock 数据用于接口与渲染验证，最终必须用真实算法结果完成操作流程；仅控制台日志或占位动效通过时只能记录为 Mock 接口通过。

## 6. 对比与执行指南

整理前后使用同一相机和相同指标规则；提供状态切换及归位动画，滑动对比可在后续增加。

执行指南由最终有效场景生成，包含物品移动顺序、接口对应关系、穿线孔与固定点、所需线长及未解决事项。存在失效路径或未完成校验时标记为未完成方案，不能按全部成功导出。

用户修改方案后，旧指南标记为过期，需重新验证并生成。水杯附近避障只表达空间规划规则，不显示“通电自检通过”或电气安全认证状态。

对比指标绑定原始快照和当前版本；增删物品、改尺寸、改线缆或统计区域后，按数据契约将受影响的基线指标标为不可比并说明原因。历史快照不随当前场景变化。刷新仅恢复后端已保存的场景、快照与任务，未提交的编辑草稿不在首版恢复承诺内。

## 7. 后续体验

AR、打印配件下载、多宿舍模板、完整手机编辑和抽屉开合交互不进入首版验收。打印扩展采用参数化 CAD 生成 STL 网格，经过切片与试装后再声明适配；不把 STL 称为切片文件，也不承诺固定打印时间。
