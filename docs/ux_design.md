# DormTopology 3D 用户体验设计

本文只定义首版用户流程与交互状态。功能边界和工期见[实施方案](implementation_roadmap.md)，字段及坐标见[数据契约](data_contract.md)，完成标准见[任务清单](project_tasks.md)。当前产品以 2026-10-18 的项目流程与交互修订为准；供应商等未接入能力仍需验收。

## 1. 场景设置与照片上传

电脑端提供完整编辑流程。当前默认空间采用固定 L 形床桌，四格书架和三层抽屉随家具尺寸固定，孔位及墙面插座位置可配置；随后上传桌面照片。视口加载 `models/dormdesk_parts/` 四份 GLB，支持旋转与缩放；失败时回退共享支撑/碰撞几何。旧项目继续显示旧参数化家具，升级内置示例前保留旧项目副本。

家具坐标、尺寸与支撑面以数据契约为准，空间配置以毫米展示。孔位必须完整位于真实桌板内，L 形空区不能吸附或摆放物品。示例尺寸不代表学校实测值，照片不能替代实际测量。

上传后展示识别进度。图片格式不支持、上传失败或识别失败时保留可用输入，提供重试和手动添加物品入口。

## 2. 物品确认与简化孪生

- 在照片上显示检测框和对应物品列表，区分保留在桌面的常用外设与待收纳杂物；允许删除误检、修改类别、补充遗漏物品。
- 手动补标采用鼠标矩形框选，提供取消和重新框选操作；触屏编辑留待后续完善。
- 框选区域可提交给后端裁剪并对接 Rodin 生成，供应商接口和版本按真实账户核验；前端不持有凭证。
- 用户确认关键物品尺寸、使用频率、允许区域与固定状态；估计尺寸保留来源标记。
- 简化长方体或圆柱体先进入场景；用户通过俯视图和属性面板校正原始位置与朝向。
- 用户确认原始状态后保存对比快照。后续拖动修改当前状态，不隐式覆盖原始快照；重新建立基线需明确操作。

确认前的物品可以预览和编辑，尺寸未确认时禁用规划。原始线缆路径可在保存快照前选择性录入；未录入仍可继续，但原始暴露线长显示未知。后续补录不能悄悄改写旧快照，需要用户显式重建基线并接受对比起点改变。

首版对比的是用户确认后的场景快照与最终方案，不宣称照片到真实空间的精确自动重建。

## 3. Rodin 外观生成

用户至少选择 1 件有辨识度的物品提交真实生成，其余物品保留简化模型或使用明确标注的缓存。单件资产显示排队、生成中、完成或失败状态。操作期间，场景与简化模型继续可用。

完成后仅替换显示模型，保留物品 ID、位置、尺寸、碰撞体和接口。首次失败时保留简化模型，重新生成期间或失败后保留已有可用外观，显示原因并允许重试。缓存命中必须显示缓存来源，演示缓存与实时任务使用相同的模型导入流程。提交结果未知时提示可能已被供应商受理及重复计费风险，不自动重提；普通查询超时沿用原任务查询。

交付 1–2 个独立单品 GLB（至少 1 个），其中至少 1 件来自真实 Rodin 任务。提供 `importModel(url, name, position)` 导入接口，导入后注册稳定 ID 并可鼠标拖动；先作为待确认草稿，补齐规划字段并确认尺寸后才进入算法。异步外观替换按已有物品 ID 执行，不创建第二件物品。

不显示未经实测的固定完成倒计时，不承诺整桌物品在 30 秒内生成。

## 4. 推荐整理与手动调整

用户点击“智能收纳”，系统在桌面、上层四格书架和右侧抽屉分区中生成推荐布局。键盘、鼠标、数位板保留在主桌面中央，课本、水杯、收纳盒等进入经用户确认的书架格或抽屉区域。规划使用关闭内腔坐标；手动编辑可打开抽屉拖入物品，内容物随抽屉移动。归位动画只展示状态变化，不作为真实搬动路线。

显示器和打印机等主要设备优先占用经确认的主视区或侧部设备区，再安排小物品；预览详情显示摆放优先级。直插适配器显示所属插孔，不能把与插排接触的外观当成有效插接；必须通过当前位姿与插孔占用检查。这些字段先在独立算法工作台展示，产品端编辑仍待接入。

- 成功：显示推荐布局及按统一规则计算的前后指标。
- 部分成功：列出无处安放的物品及原因；保留其当前位置，不把它们计为已收纳。
- 无可行方案：保留当前场景，说明冲突及可调整条件。

推荐结果先预览，用户选择接受或取消；预览及动画不写入正式场景、不增加版本。接受后由后端复核并保存，返回新版本才更新当前状态；取消保留原场景。预览期间出现编辑草稿或版本变化时禁止应用旧建议，提示重新规划。

产品推荐整理默认在同高度重叠的物品实体之间保留至少 20mm 水平净距，同时保留穿线孔出线空间；不同层互不挤占，明确直插插排的适配器保留接触关系。间距不足时列出相关物品，空间不足则保留原位并说明原因，不自动降低间距。此规则用于推荐、接受结果及恢复历史候选方案；已有项目和手动拖动不会被自动搬开，恢复原始布局及撤销重做保留原状态语义。

用户可用鼠标左键在桌面上拖动物品、旋转物品，或在属性面板输入位置和尺寸。鼠标操作需区分选择、拖动和相机控制；尺寸与位置输入为精确调整入口。手动拖动允许干涉：松开保存最后落点，标示相交、越界或悬空，可撤销；指针取消不提交。尺寸修改（输入和 Ctrl 角点缩放）必须通过物品碰撞、家具碰撞及房间边界校验，失败保留原尺寸，不产生历史记录。Q/E 每次旋转 10°。物品拖动自动吸附支撑面、近邻中心与边缘；未命中锚点使用 10mm 网格。尺寸编辑使尺寸和接口待重新确认，单纯平移或旋转保留局部接口确认。所有编辑在后端保存成功后形成新版本，使旧走线与指南失效；检查当前布局后，由用户触发重新布线，首版重验全部请求线缆。保存失败保留草稿并提示重试，不将草稿冒充已保存场景。

首版采用几何约束检查；刚体反馈、自由堆叠和装箱游戏属于后续扩展。

## 5. 接线与路径规划

工作台右键物品选择「表面描点」，跳转到只展示该物品的独立标记页面。模型可旋转、缩放，并切换正面、背面与顶面；点击真实表面标记接口，填写名称和说明后保存。描点表单提供接口类型选择，新标记默认类型为「电源插头」，并默认勾选「受电口（电源输入）」，用户可修改类型或取消勾选；已有接口编辑时带入原配置。允许继续标记或保存并返回工作台；确认接口后「以此点连线」返回场景选择另一端。独立页面的取景与模型展示变换不修改原物品的尺寸、位置、旋转或可见性，进入与退出保留工作台撤销历史；刷新可恢复已保存标记，未保存草稿不落盘。本轮按用户要求仅实现电脑端，采用模型与接口设置左右分栏。

常用设备提供接口模板。用户进入接线模式后，确认接口类型、连接对象与线径；当前工作台支持接口局部位置、方向编辑，任意物品表面点击取点仍按任务清单验收。走线规划不要求输入现有线长；成功后展示路径长度、预留及所需备线长度。已有数据提供现有线长时继续校验是否足够，未知时不列为缺失输入或声称长度充足。接口保存为物品局部坐标，随物品移动和旋转更新。提供粗线/细线切换，分别影响实际线径、净空与显示粗细；产品不按粗细限制物理最小转弯半径，也不要求用户输入该值。历史领域场景指定正数半径时继续复查。

用户选择起点与终点；可连接兼容的设备接口、插排孔位、墙插或网口。线材电气类型与粗细分开记录，粗细默认值仍需用户确认。提供 4/6/8 位插排规格选择，可在场景中放置并调整位置，各插孔独立选择；同一插孔不能被重复占用，多线缆可沿有足够净空的通道汇聚。切换规格后，提示用户重新指定被移除孔位上的连接，旧路径失效。

规格切换和改接先作为同一份草稿；仍有悬空接口时禁止保存和规划，取消恢复原规格及原连接。尺寸或接口修改后须完成重新确认；已引用但未确认的接口不能开始走线。

墙面呈现默认离地 0.30m 的网口与双孔插座面板，默认高度锚点以数据契约为准；允许在墙面内调整，左右对应 X，上下对应 Y，深度 Z 固定。必须支持沿 Y 轴调节并将新坐标传给走线模块。桌体、插排或面板位置改变后，相关路径必须重新验证。

走线默认优先沿桌面后侧边缘的并排通道，打字区、水杯区和桌下腿部活动区不再阻挡线缆；这些区域继续约束物品摆放。后缘偏好不能绕过桌板、柜壳、设备本体、接口引出方向与策略检查。线缆之间不比较线径和间距，可共线或交叠，界面不再生成线间距提示。

走线面板提供桌后理线扣、桌下扎带和桌下集线槽预设，从真实桌板推导安装位置；添加后显示“待安装建议”，用户另行勾选“已安装”，可删除或撤销。配件位置始终显示，不依赖是否已有成功线缆。配置与安装状态随项目保存和刷新恢复；任何配件编辑、撤销或重做都使旧走线和指南失效。

“复核已安装配件的支撑跨距”默认关闭，用户可显式开启并设置最大悬空跨距；关闭时显示支撑未评估，不能把后缘通道或建议配件当作现实安装。开启后仅使用确认安装的配件，超限时提示补充固定件或调整路径，不显示有效连接。界面确认不代替现实安装、承载或施工可行性核验。

逐根走线完成后，在“集线槽复查”中展示后端返回的推荐/已验证组合、成员线缆、共享走向长度与未采用原因；宽度不足时显示线束宽度及可用槽宽。推荐保留原逐线方案，不改变当前有效性或线长，也不自动勾选安装。确认安装并将配置同步为新版本后再规划；只有所有当前线缆的认证场景与版本匹配且没有待重算线路时展示该结果，旧结果在配件或场景编辑后隐藏。真实安装和完整指南步骤仍需验收。

路径策略受场景几何约束：

- “走过线孔”：经场景中明确配置的穿线孔下行。
- “走背板后”：绕至背板后方，经具有足够净空的通道下行。

“智能布线”按钮提供以上两种策略切换，两种策略均须完成首版验收。缺少对应通道时禁用该策略并说明原因，同时记录该场景不具备该策略条件，不能以禁用代替演示场景双策略验收。规划中显示状态；成功后按已验证控制点和采样点绘制路径，线长不足、接口遮挡或无可行路径时显示具体原因，不能展示成功连线。规划采用路径搜索与平滑后复查，不能用样条动画替代避障验证。

部分成功时只绘制本次结果中 `valid` 的线缆，失败线显示原因并清除其旧路径，整体标为未完成；不能把历史有效线或失败线的空路径计为当前成功。任一当前线缆失败时，完整暴露总长显示未知，不展示改进比例。

“智能收纳”和“智能布线”分别接收数据契约中的两类 JSON 结果，并支持导出相应 JSON 文件。提供本地 Mock 数据用于接口与渲染验证，最终必须用真实算法结果完成操作流程；仅控制台日志或占位动效通过时只能记录为 Mock 接口通过。

## 6. 前后对比与整理动画

工作台与最终页使用按住对比：鼠标、触屏或空格/回车按下显示原始快照，松开、取消、失焦后恢复。查看快照不改写项目或历史；工作台仍保留历史方案恢复入口。

项目最终页为 `/projects/:id/result`，以原始快照与当前保存结果生成逐件动画，支持播放、暂停、前后步骤和重播。用户跟随动画整理真实桌面。移除产品执行指南、导出指南、打印与方案并排对比入口；旧 `guide` / `compare` 链接兼容打开动画页。不存在快照或没有差异时如实说明，不虚构移动；无效/过期线缆不渲染为有效路径，当前摆放问题仍显示提醒。动画是位置变化演示，不代表搬运轨迹经过碰撞规划。

历史快照不随当前场景变化。对比和动画仅使用当前项目及其基线，增删物品分别呈现移入/移出；本次未增加新后端指南协议。

## 7. 后续体验

AR、打印配件下载、多宿舍模板、完整手机编辑不进入首版验收；当前抽屉推拉与内容物随动按新增交互要求验收。打印扩展采用参数化 CAD 生成 STL 网格，经过切片与试装后再声明适配；不把 STL 称为切片文件，也不承诺固定打印时间。

## 固定 L 形桌分区补充（2026-10-18）

整理面板折叠分区说明，用户开启参考线后，视口显示显示器、倾斜笔记本、键盘、鼠标垫/鼠标、常用杂物、第二格学习用品，以及手部和座位禁放区；固定家具不显示旧的键鼠横移、水杯四角选择控件。精确范围、预制分类与旋转规则见[数据契约](data_contract.md#固定家具的产品摆放分区2026-10-18)。超大物品不能通过缩小、越界或忽略碰撞自动放入专用区。

默认示例 v8 将插排初始位置设在右后回台，避开长槽中线；旧示例按已有迁移机制另存。显示器保持长槽正中、笔记本内转 20°，右侧外段专用于常用杂物，打印机安排左侧。规划和应用版本冲突仍保留原场景；不同浏览器的内置示例由独立远端键隔离，避免尚未开始计算就出现 409。

## 项目与工作台修订（2026-10-18）

首页统一以项目为单位：创建项目包含命名、确认空间、添加物品，完成后自动载入该项目工作台；未完成的项目从首页继续创建。空间预览只允许面向墙内的视角，禁用平移并限制方位角，避免转到墙背。工作台为项目编辑器，顶栏保留整理、按住对比与更多操作；规则、指标、历史和高级设置按需展开。窄屏将左右面板收进抽屉，保留场景和主要操作。

右键物品选择“表面描点”，进入只显示该模型的页面；自由转动模型视角，在表面取点、确认接口并连线，退出返回工作台。切换标记物品时同步模型，相机聚焦新目标；描点页面禁止普通摆放拖动和 Q/E 编辑。

抽屉旁柜体保持开放，无额外柜门；柜内上下两层可拖入、自动吸附，也可从物品属性直接放入。抽屉开口只对应一个随动底板吸附目标，拖入后绑定、拖出后解除；属性面板和更多菜单均提供开合控件。PDU 可拖到桌下背板安装，默认生成于背板中间，插孔面朝座位。笔记本新增/替换预制模型时默认朝座位，自动整理仍遵守右侧内转 20° 的专用区要求。
