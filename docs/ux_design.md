# DormTopology 3D（寝空拓扑）产品策划案与研发分工指南

> **定位**：基于 **Hyper3D (Rodin)** 与多模态 AI Agent 的高校宿舍空间“智能整理装箱 + 电线拓扑避障 + 3D 打印物理落地”全流程孪生系统。

---

## 一、 端到端用户全旅程地图 (User Journey Map)

用户从打开应用到最终解决问题，全程遵循 **“极简输入（10秒） $\to$ 自动化孪生（30秒） $\to$ 解压交互体验（1分钟） $\to$ 物理制造落地（成果交付）”** 的闭环，共分为 5 个连续阶段：

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                                   用户核心体验路径                                     │
├──────────────┬──────────────┬──────────────┬──────────────┬────────────────────────────┤
│ 1. 随手拍诊断 │ 2. 秒级孪生  │ 3. 智能收纳  │ 4. 智能理线  │ 5. 实体制造                │
│ (拍照上传)   │ (1:1 映射)   │ (装箱飞入)   │ (贴墙避障)   │ (3D打印卡扣 + 走线指南)    │
└──────────────┴──────────────┴──────────────┴──────────────┴────────────────────────────┘
```

## 二、 五大阶段深度体验流程细化

### 阶段 1：随手拍与多模态安全感知 (Snap & Perceive)
* **用户输入**：
  - 用户坐在椅子前，打开手机/网页端，拍摄 1~2 张桌面整体照片（可包含右侧转角与桌下柜子）。
  - *可选微调*：选择学校预设标准模板（如“上科大标准上床下桌”），支持拖动滑块微调桌面宽度（默认 104cm）、净深（默认 55cm）。
* **AI 感知与安全预警 (诊断态)**：
  - 多模态视觉大模型秒级完成目标检测（Bounding Box 与类别识别）：
    - **带电外设**：显示器、机械键盘、笔记本电脑、台灯、手机充电线、排插等；
    - **非电气杂物**：课本、水杯、收纳盒、胶带圈、零食等；
  - **生成桌面“安全与混乱热力图”**：
    - 🔴 **高危预警点**：例如水杯与裸露插排间距仅 15cm，标红警示“存在打翻短路漏电隐患”；
    - 🟡 **空间挤占区**：键盘前可用操作深度仅剩 10cm，活动空间被压缩 70%；
    - 🔵 **线缆缠绕指数**：识别出 8 根电线交织成网，给出当前桌面健康度评分（如：*混乱度 87/100*）。

---

### 阶段 2：1:1 物理空间孪生构建 (Digital Twin Rebuild)
* **后台自动化管线**：
  - **空间容器即时加载**：前端以 WebGL/Three.js 毫秒级载入纯净 CAD 底座（`models/dorm_desk.glb` 对应的标准床架、桌板、后挡板、书架与下桌抽屉柜）；
  - **动态资产并发生成**：调用 **Hyper3D (Rodin) API / MCP**，将照片中识别出的水杯、键盘、显示器等物品并行生成为带 PBR 贴图的独立 3D 资产（`.glb`）；
  - **物理贴合引擎执行**：后台 Headless Blender 自动执行法向校准与接触面吸附，所有物品底面严丝合缝对齐桌板标高 $Z = 0.770\text{ m}$，鼠标落在鼠标垫表面 $Z = 0.773\text{ m}$；
* **用户感知**：
  - 用户屏幕上的 2D 照片平滑渐变为可 360° 任意旋转、缩放的 **3D 孪生实景**（对应 `models/dorm_desk_assembled.glb`），物品位置与真实书桌完全一致。

---

### 阶段 3：智能空间整理拓扑（3D 杂物归纳与三维装箱）
用户点击界面核心大按钮：**【✨ 智能空间重构】**，触发极具治愈感的物理动效：

#### 1. 动效呈现：“磁吸飞入”与空间装箱（三维装箱算法驱动）
- **功能分区智能规划**：
  - **核心操作区**（主桌面中心）：仅保留显示器、键盘、鼠标垫、数位板，清空出 $55\text{ cm}$ 完整打字空间；
  - **垂直扩展区**（桌上四格书架）：分散的课本、数码小配件、备用充电头沿着抛物线轨迹，**整整齐齐自动“飞入”书架格与横隔层**；
  - **隐蔽收纳区**（右侧 90° 内转抽屉柜与开放层）：胶带圈、零散文具自动落入顶层抽屉，备用设备收纳至后方双层开放格。
- **用户掌控感（交互式微调）**：
  - 用户可以用鼠标/手指拖动任意 3D 物品，系统自带**网格磁吸（Snapping）与碰撞体刚体反馈**，绝不允许穿模；
  - 提供**“解压装箱模式”**：多余的闲置包装盒可一键打包装箱。

---

### 阶段 4：强弱电避障路由拓扑 (Cable Routing & Auto-Bundle)
#### 1. 接口语义自动定位
- 系统自动标定各设备的电源/信号接口三维坐标：显示器背部电源/HDMI、笔记本 Type-C/电源、台灯引线、键盘数据线、排插孔位。

#### 2. 三维样条曲线避障路由 (Catmull-Rom Routing)
- 算法自动计算最优路径：
  - **安全避障**：强制绕开水杯活动范围（安全半径 25cm）与双手打字区；
  - **路径吸附**：优先走后背板底部的开孔、贴着桌板底面暗槽延展、顺着床架 $6\text{ cm}$ 方管立柱内侧向下走线。

#### 3. 动态视觉效果：一键贴墙聚束（Auto-Bundle Animation）
- 原本散乱铺在桌面上的 8 根不同颜色电线，以流畅的样条弯曲动画，**“唰”地一下自动收拢成两股主干线束，紧紧吸附在后挡板下缘与立柱侧边**；
- **通电自检动画**：收拢完成后，线缆上浮现微弱的柔光流动粒子效果，终端设备亮起绿色通电指示灯。

---

### 阶段 5：实体制造交付与 3D 打印 (Physical Delivery & 3D Print)
彻底跳出传统收纳软件“纸上谈兵”的局限，提供**线上方案到线下实体的真正闭环**：

```
┌────────────────────────────────────────────────────────┐
│                阶段 5: 最终交付物面板                  │
├───────────────────────────┬────────────────────────────┤
│   📄 落地执行指南卡片     │    🖨️ 专属定制 3D 打印配件   │
│   · 动线摆放顺序表 (1-5步) │   · 立柱理线卡爪 (STL 下载)    │
│   · 线缆扎带绑扎节点图示  │   · 边缘耳机/电线挂钩 (STL)   │
└───────────────────────────┴────────────────────────────┘
```

1. **一键生成《寝室理线与收纳执行卡》**：
   - 步骤清楚列出：*“1. 先将显示器线缆沿后背板开孔穿下；2. 用 1 号卡扣将排插总线固定在右前立柱内侧……”*。
2. **专属卡扣 3D 打印文件自动生成（Rodin 核心制造能力）**：
   - 系统检测到该床桌立柱为 $6\text{ cm}$ 方管、桌板为 $2.5\text{ cm}$ 实木板，**直接调用 Rodin API 生成结构级 STL 卡扣模型**（预留 $0.2\text{ mm}$ 弹性公差）；
   - 用户可直接在界面点击 **【📥 下载 3D 打印切片文件 (.stl)】**，送去学校创客空间或宿舍 3D 打印机，15 分钟即可打印出实体配件，卡在床柱上使用！
3. **AR 实景透视投影**：
   - 点击 **【📱 AR 查看】**，手机相机扫一扫真实书桌，收纳后的 3D 摆放位置与走线虚实重叠，指引精准摆放。

## 三、 团队 3 人 48 小时并行研发分工方案

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                    DormTopology 3D 三大专业大块分工架构                      │
├──────────────────────┬──────────────────────────────┬────────────────────────┤
│ 模块一：杂物分拣与   │ 模块二：智能走线与           │ 模块三：Web3D视口集成  │
│ 三维装箱系统 (物品向)│ 电线拓扑路由 (走线向)        │ 与制造落地 (平台/管线) │
├──────────────────────┼──────────────────────────────┼────────────────────────┤
│ · 图像多模态物体识别 │ · 外设强弱电接口定位         │ · Three.js 统一视口搭建│
│ · 三维装箱求解算法   │ · 三维样条避障算法 (绕水杯)  │ · Rodin 资产生成管线   │
│ · 空间容积与分区规划 │ · 一键贴墙聚束与收拢动效     │ · 3D打印卡扣 STL 生成  │
│ · 杂物飞入动画数据   │ · 通电自检粒子流光           │ · 平台UI与手机 AR 投射 │
└──────────────────────┴──────────────────────────────┴────────────────────────┘
```

### 👤 模块一：【杂物智能分拣与三维装箱系统】（同学 A）
* **定位**：负责“空间物理整理”，解决桌面拥挤。
* **开发职责**：
  1. 调用多模态大模型对上传的凌乱桌面照片进行目标识别与分类，估计尺寸；
  2. 编写三维装箱优化算法（3D Bin Packing），根据书架 4 格与抽屉 3 层的几何约束，计算物品飞入的最优落位坐标 `(x, y, z)` 与姿态；
  3. 计算每件物品从散落位置到目标格子的抛物线贝塞尔插值控制点；
* **对外交付接口**：输出 `packing_result.json`。

### 👤 模块二：【智能走线拓扑与电线避障路由系统】（同学 B）
* **定位**：负责“电线盘丝洞”，打造核心硬核算法与最炸裂的视觉动效。
* **开发职责**：
  1. 标定各外设（显示器、笔记本、台灯、主机、排插）的电源与信号接口三维坐标；
  2. 采用 Catmull-Rom 样条曲线计算避障走线，**强制避开水杯危险区（半径 25cm）**，贴合立柱与背板暗槽；
  3. 编写线缆一键贴墙聚束动画插值算法，以及绿色通电流光粒子着色器效果；
* **对外交付接口**：输出 `cable_routing.json`。

### 👤 模块三：【Web3D 视口整合、Rodin 资产管线与 3D 打印落地】（同学 C）
* **定位**：负责“整体平台集成、资产管线与实体制造”。
* **开发职责**：
  1. 基于 Three.js 或 `<model-viewer>` 搭建全屏 3D 视口，集成已建好的 `dorm_desk.glb` 和 `dorm_desk_assembled.glb`，接入模块 A 与 B 的数据驱动动画播放；
  2. 接入赞助商 Hyper3D (Rodin) API / MCP 动态生模接口；
  3. 跑通 Headless Blender 自动化脚本，根据桌板（25mm）和立柱（60mm）尺寸自动导出带 0.2mm 公差的 `custom_clip.stl`；
  4. 赛中去学校创客空间 3D 打印 2 个卡扣实体，作为路演秘密武器；
  5. 配置手机扫码 AR 投射功能。
* **对外交付物**：可运行的 Web 端完整 Demo 网页 + 导出的 `custom_clip.stl` + 现场 3D 打印实体卡扣。
