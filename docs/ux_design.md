# DormTopology 3D 用户体验设计

本文只定义首版用户流程与交互状态。功能边界和工期见[实施方案](implementation_roadmap.md)，字段及坐标见[数据契约](data_contract.md)，完成标准见[任务清单](project_tasks.md)。本文描述的是待实现体验。

## 1. 场景设置与照片上传

电脑端提供完整编辑流程，手机首版支持图片上传、本地预览以及场景和结果查看。用户选择标准桌面，确认桌宽、桌深和桌面高度，然后上传一张桌面照片；浏览器摄像头拍摄作为可选入口，不影响文件上传流程。最终视口加载 `models/dorm_desk_assembled.glb`，支持 360° 旋转与缩放；开发阶段可使用参数化几何。

默认尺寸使用数据契约中的演示配置，界面以厘米展示；所有默认值都可编辑，并明确标注为示例值。照片不能替代实际测量。

上传后展示识别进度。图片格式不支持、上传失败或识别失败时保留可用输入，提供重试和手动添加物品入口。

## 2. 物品确认与简化孪生

- 在照片上显示检测框和对应物品列表，区分保留在桌面的常用外设与待收纳杂物；允许删除误检、修改类别、补充遗漏物品。
- 手动补标采用鼠标矩形框选，提供取消和重新框选操作；触屏编辑留待后续完善。
- 框选区域可提交给后端裁剪并对接 Rodin 生成，供应商接口和版本按真实账户核验；前端不持有凭证。
- 用户确认关键物品尺寸、使用频率、允许区域与固定状态；估计尺寸保留来源标记。
- 简化长方体或圆柱体先进入场景；用户通过俯视图和属性面板校正原始位置与朝向。
- 用户确认原始状态后保存对比快照。后续拖动修改当前状态，不隐式覆盖原始快照；重新建立基线需明确操作。

首版对比的是用户确认后的场景快照与最终方案，不宣称照片到真实空间的精确自动重建。

## 3. Rodin 外观生成

用户至少选择 1 件有辨识度的物品提交真实生成，其余物品保留简化模型或使用明确标注的缓存。单件资产显示排队、生成中、完成或失败状态。操作期间，场景与简化模型继续可用。

完成后仅替换显示模型，保留物品 ID、位置、尺寸、碰撞体和接口。失败时保留简化模型，显示原因并允许重试。缓存命中必须显示缓存来源，演示缓存与实时任务使用相同的模型导入流程。

交付 1–2 个独立单品 GLB（至少 1 个），其中至少 1 件来自真实 Rodin 任务。提供 `importModel(url, name, position)` 导入接口，导入后注册物品并可鼠标拖动；异步外观替换按已有物品 ID 执行。

不显示未经实测的固定完成倒计时，不承诺整桌物品在 30 秒内生成。

## 4. 推荐整理与手动调整

用户点击“智能收纳”，系统在桌面、上层四格书架和右侧抽屉分区中生成推荐布局。键盘、鼠标、数位板保留在主桌面中央，课本、水杯、收纳盒等进入经用户确认的书架格或抽屉区域。抽屉使用固定可访问状态，不要求开合交互。归位动画只展示状态变化，不作为真实搬动路线。

- 成功：显示推荐布局及按统一规则计算的前后指标。
- 部分成功：列出无处安放的物品及原因；保留其当前位置，不把它们计为已收纳。
- 无可行方案：保留当前场景，说明冲突及可调整条件。

用户可用鼠标左键在桌面上拖动物品、旋转物品，或在属性面板输入位置和尺寸。鼠标操作需区分选择、拖动和相机控制；尺寸与位置输入为精确调整入口。无效摆放应显示冲突并恢复到上一次有效状态，已连接物品移动后使相关走线失效并触发复查。

首版采用几何约束检查；刚体反馈、自由堆叠和装箱游戏属于后续扩展。

## 5. 接线与路径规划

常用设备提供接口模板。用户进入接线模式后，可在任意物品表面任意点击取点或编辑接口位置，并确认接口类型、连接对象、线长、线径和最小弯曲半径。表面取点写入物品局部坐标，随物品移动和旋转更新。提供粗线/细线切换，加载不同线径与弯曲半径预设并允许确认修改，渲染粗细与实际线径一致。

用户选择起点与终点；可连接兼容的设备接口、插排孔位、墙插或网口。线材电气类型与粗细分开记录，粗细默认值仍需用户确认。提供 4/6/8 位插排规格选择，可在场景中放置并调整位置，各插孔独立选择；同一插孔不能被重复占用，多线缆可沿有足够净空的通道汇聚。切换规格后，提示用户重新指定被移除孔位上的连接，旧路径失效。

墙面呈现默认离地 0.30m 的网口与双孔插座面板，默认高度锚点以数据契约为准；允许在墙面内调整，左右对应 X，上下对应 Y，深度 Z 固定。必须支持沿 Y 轴调节并将新坐标传给走线模块。桌体、插排或面板位置改变后，相关路径必须重新验证。

路径策略受场景几何约束：

- “走过线孔”：经场景中明确配置的穿线孔下行。
- “走背板后”：绕至背板后方，经具有足够净空的通道下行。

“智能布线”按钮提供以上两种策略切换，两种策略均须完成首版验收。缺少对应通道时禁用该策略并说明原因，同时记录该场景不具备该策略条件，不能以禁用代替演示场景双策略验收。规划中显示状态；成功后按已验证控制点和采样点绘制路径，线长不足、接口遮挡或无可行路径时显示具体原因，不能展示成功连线。规划采用路径搜索与平滑后复查，不能用样条动画替代避障验证。

“智能收纳”和“智能布线”分别接收数据契约中的两类 JSON 结果，并支持导出相应 JSON 文件。提供本地 Mock 数据用于接口与渲染验证，最终必须用真实算法结果完成操作流程；仅控制台日志或占位动效通过时只能记录为 Mock 接口通过。

## 6. 对比与执行指南

整理前后使用同一相机和相同指标规则；提供状态切换及归位动画，滑动对比可在后续增加。

执行指南由最终有效场景生成，包含物品移动顺序、接口对应关系、穿线孔与固定点、所需线长及未解决事项。存在失效路径或未完成校验时标记为未完成方案，不能按全部成功导出。

用户修改方案后，旧指南标记为过期，需重新验证并生成。水杯附近避障只表达空间规划规则，不显示“通电自检通过”或电气安全认证状态。

## 7. 后续体验

AR、打印配件下载、多宿舍模板、完整手机编辑和抽屉开合交互不进入首版验收。打印扩展采用参数化 CAD 生成 STL 网格，经过切片与试装后再声明适配；不把 STL 称为切片文件，也不承诺固定打印时间。
