# 整理算法复查与书本立放

复查日期：2026-10-18。范围为产品场景适配、领域布局、共享几何与方案应用。

## 本次调整

书本（`book` / `books`）优先立放，立放几何不可行时允许平放。先满足支撑、净高、碰撞、20mm 物品间距等硬约束，再比较立放、偏好区域、接口净空、书脊朝向、连续面积与取用成本。平放原始书本优先以书脊朝用户的水平朝向摆放；空间不允许时仍可使用另一个允许朝向。高频书或明确桌面偏好不被强制搬到书架。

尺寸与原始碰撞数据保持不变，使用底心重新锚定的离散翻转。已有立式资产不重复翻转；固定和锁定书本保持原姿态。外观、碰撞、接口、预览、应用、撤销、快照、对比和指南都传递书本姿态。字段见[数据契约](data_contract.md#21-物品)。不拆开整组书模型，不进行刚体稳定性或书挡校验。

## 已复现的问题

### P1：连续面积未采用复合碰撞体的真实投影

位置：`packing/area.py` 的 `DesktopGrid.item_mask` 调用 `geometry.footprint`，后者以 `size_m` 矩形计算。实际碰撞、支撑检查已经使用复合凸体，面积评分却与其不一致。

复现：桌面 1.0×0.6m，相同物品位置、相同 0.1×0.1m 碰撞底面，声明底面分别为 0.4×0.4m 与 0.1×0.1m，连续可用面积分别为 **0.44m² / 0.59m²**，相差 **0.15m²**。只有声明尺寸改变，物理占地没有改变。

影响：可能错误排名布局候选，也使复合模型的面积指标失真。当前不是碰撞漏检问题。应将各真实凸部件 XZ 投影栅格化后取并集，不能仅用整体 AABB 填实凹口。本次只修正书本姿态后的矩形轴序，未修复一般复合体面积口径。

### P2：有完整可行布局时，贪心算法仍可能返回部分完成

位置：`packing/planner.py` 的排序、`_choose` 及单向回滚。

复现：目标区 A/B 各只能放一件物品。高优先级物品允许 A/B 且偏好 A，低优先级物品只允许 A。算法先把前者放 A，后者保留原位，返回 `partial`；改为前者放 B、后者放 A，`validate_layout` 返回 `geometry_valid=true` 且 `issues=[]`。

这是已文档化的启发式限制，不是无解证明。当前回滚没有交换、重排或重新搜索。建议先加入有次数上限的两物品交换/局部修复，保留最终全场几何复查。

## 从实现确认的限制

| 优先级 | 现状与位置 | 影响 | 建议 |
| --- | --- | --- | --- |
| P2 | `_candidates` 组合边界、中心、原位和障碍边缘，按靠边程度筛至每区域、朝向、姿态最多 128 个合法候选 | 先截断再评分，可能丢掉更好的内部位置；128 不限制前面全部几何检查的工作量 | 多样化保留候选，分开记录生成、校验、评分耗时 |
| P2 | `_choose` 按偏好区域、接口、面积、取用成本逐级比较；书本另加入立放及书脊朝向 | 一个前级改善可压过后面全部成本，高频设备不一定更近 | 明确产品取舍；评估完整场景的总取用成本和同组对齐 |
| P2 | 多个书架位置可能重复计算同一桌面占用位图的连通面积；接口代价重复准备凸体 | 多物品、多区域、多部件会增加耗时；候选数上限不是整体耗时上限 | 缓存相同占用位图的连通面积，增加统计后实测预算 |
| P2 | 整理只检查接口附近 25mm 引出段，不共同求解整根线缆 | 布局 `success` 仍可能走线失败 | 保留分别报告；对少量候选做受限走线复评 |
| P3 | 书本逐件摆放，仍保留统一 20mm 净距，无书列组、书挡或稳定性模型 | 不保证紧密排书、同一前沿或实物站稳，整组 GLB 只能整体翻转 | 另行设计分组与稳定性约束，不悄悄取消全局净距 |
