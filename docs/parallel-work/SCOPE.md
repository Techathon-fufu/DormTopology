# 本轮前端范围决定（2026-10-18，仅分析）

依据本轮用户要求，覆盖此前冲突报告中“保留执行指南”的建议。尚未开始产品代码修改、正式合并或提交。

## 主流程

我的空间 → 创建项目（空间、物品两段）→ 项目工作台 → 整理演示最终页。

- 新建名称整合入创建流程，不再独立增加一页。创建期间保留草稿，完成尺寸/物品必要确认后自动打开工作台；返回首页后可继续未完成的创建。
- 工作台不再展示 1–4 步。保留项目名称、返回我的空间、设置入口、撤销/重做和当前主要操作。项目后续改空间或补物品不会重新进入完整创建流程。
- 最终页采用远程 ResultPage 的回放方向，按件演示原位置到已接受位置；提供播放/暂停、上一步/下一步、重播、按住查看原布局、返回编辑。动画仅改变显示，不重复应用方案或修改项目。
- 移除执行指南页面、导出/打印入口、指南生成链路及对应用户文案；旧 guide 地址兼容跳转到最终页。保留原始快照、当前有效结果、版本检查与失败信息。
- 大众默认流程不展示独立多方案指标对比页；历史方案为次级入口，保留已有保存数据及恢复能力。对比旧地址兼容最终页。

## 界面

- 以现有首页为统一视觉基准，提取共用色彩、字体层级、圆角、按钮、留白和日夜主题，覆盖创建、工作台、描点和最终页。工作台保留适合操作的紧凑布局。
- 左侧负责添加、选择、属性和物品相关处理，右侧负责整理/理线引导及确认；选中物品不替换右侧流程。仅桌面端，不恢复移动端布局。
- 一个阶段一个主操作；长说明、模型技术状态、服务详情、算法指标和调试入口移入次级详情。必须处理的失败保留短原因和明确操作，不把失败藏起来。
- 空间创建采用远程实心桌面与精简配置；不恢复书架层数/出线孔配置、重复空间摘要或多个视角按钮。

## 预览与模型

- 空间配置的小预览单独限制相机：正面和室内侧可转，避免绕到后墙/侧墙外；限制平移、缩放和垂直角度。约束需基于实际房间边界，不能仅隐藏墙背面或只限制水平角度。不全局限制工作台和独立物品查看。
- 对比保持室内侧视角的同时保留足够空间总览，不让相机穿墙、穿地或进入家具。
- 杯子底面闪烁先复现，再区分重合面、面朝向、放置穿桌和自阴影。杯子正常内壁不能被当成错误全部翻面。
- 将可验证的显示几何检查接入预制物品和实际手动导入模型的显示入口：修复可明确判定的错误；开放、空心、透明、带动画或无法安全自动修复的资产保留原结构并提供明确降级。不能承诺任何损坏模型都无条件自动修好。
- 保留已有手机、鼠标垫和底座面朝向修复；不改源 GLB，不靠抬高全部物品或关闭全局深度/阴影掩盖问题。外观修正不得擅改碰撞/接口/尺寸。
- 物品材质提高明度区分和饱和度：深灰键鼠、深色屏幕、偏暖浅木家具、适中深度的杯体和收纳色。保留导入模型原有贴图与作者材质；两种 UI 主题下都检查模型辨识度。
- 可移动物品的新建默认宽/高/深均乘 0.85，包括新示例和物品库的未确认默认值。家具、房间、固定墙插不缩放；既有项目、实测/用户确认尺寸及导入模型原尺寸不改。
- 尺寸缩小写入真实物品尺寸，显示、现有碰撞计算和局部接口按同一比例处理；保持底面支撑关系，防止视觉缩小但碰撞仍大。接线仍按既有确认/失效规则处理，不改理线接口契约。

## 合并与协作边界

- 保留现有 Q/E 10°旋转、Ctrl 缩放、统一抽屉坐标、背板安装、书本姿态、场景/基线保护和本地渲染优化。以远程实心家具、新创建/结果页方向为整合基础。
- 前后端理线 API、请求/响应契约、同步恢复、路由算法和服务实现暂不修改。共享转换文件中的理线逻辑也不顺带整理；冲突涉及这些代码时单独记录，不用旧分支覆盖正在优化的内容。
- 本轮也不扩展到新的后端整理算法。已经存在的他人后端/书本相关修改原样保护，不能包含在本轮前端提交中。
- 先在隔离目录整合前端，按主题划分提交，最终回归通过再更新本地 main；不推送。合并过程中如出现后端 API 选择冲突，留出明确边界交由负责者整合。

## 验收顺序

1. 创建项目草稿恢复、完成后进入工作台、已有项目再次打开与编辑。
2. 首页到创建/工作台/描点/最终页的视觉一致性、主要操作清晰度；桌面完整流程。
3. 空间预览连续旋转/拖动/缩放不能看到墙背面或穿墙。
4. 杯子、已修复三种预制物品和手动导入测试资产，在多角度/距离/桌面接触下检查，含阴影与像素/表面证据。
5. 85%默认尺寸只应用一次、旧数据不变、碰撞/接口/支撑一致。
6. 最终页逐件回放与暂停/跳步/前后对照，播放不改保存状态；无有效结果时明确引导，失败线缆不作为成功动画显示。
7. 前端类型、构建、必要浏览器与状态回归；确认未改动协作中的后端理线 API。
