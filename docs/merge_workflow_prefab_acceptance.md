## 合并结果

- 产品工作台保留最新 main 的后台整理/走线任务、版本同步、指南及原子应用接口，前缀仍为 `/api/v1`。
- 独立 `/workflow` 保留完整契约场景、基线确认、实时整理、当前版本走线、对比与 Markdown 指南，API 调整为 `/api/v1/workflow`，避免同名场景和健康检查接口互相覆盖。
- 统一应用工厂通过 lifespan 创建和关闭两套服务。工作流使用独立 SQLite 文件，默认在产品数据库同目录的 `workflow.sqlite3`；照片位于同级 `workflow-data/photos/`。环境变量可分别设置。
- 桌体按贡献者交接采用 body + 三只独立抽屉，统一到 main 的 `models/dormdesk_parts/` 路径和固定家具共同偏移；保留源资产、材质、真实 L 桌面、书架/抽屉支撑、实体碰撞和开孔桌面。抽屉施加桌体的同一矩阵，并保留独立推拉。
- 12 个单品 GLB 和生成碰撞数据保留；修正底心模型与父级半高偏移叠加，模型和碰撞同步匹配编辑后的尺寸。模型实例保留源根节点变换，切换资源时不显示旧实例。示例种子升级 v5，避免来源分支两个不同的 v4 混用；旧示例沿用 main 的归档策略。
- 抽屉取消操作不再被当作点击；结束操作检查指针 ID，防止重复结束。侧视机位改为室内斜前方，避免墙和示例物品遮挡抽屉正面。
- 正式抽屉测试等待动画收敛并检查真实指针操作。画面检查改用覆盖、亮度方差和空间分布，拒绝空白或均匀画面，不依赖资产配色数量；等待桌体资产加载后再检查。
- 17 件预制碰撞的复查曾超过 120 秒。实测剖析定位重复世界几何变换、包围盒和 SAT 投影，增加按不可变几何值与位姿索引的有界缓存、整体 AABB 早退和三维点积热路径；保留精确凸体、容差和候选预算，并回归位置/旋转/碰撞/尺寸修改的缓存失效。复查能返回真实不可行结果，未修改判定制造成功。
- 删除贡献者明确标记“用后删除”的 5 个临时脚本/探针；保留正式资产、抽屉、产品整理与工作流测试。
